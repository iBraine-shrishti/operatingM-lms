# operatingM-LMS

Operating Media LMS Portal - Modern Learning Management System built with React, TypeScript, Tailwind CSS, and Vite.

## Features
- **Dual User & Role-Based Experience**:
  - **👑 Admin / Instructor**: Full management suite including course builder, syllabus editor, quiz creator, student roster, question discussions, and revenue analytics.
  - **🎓 Student / Learner**: Dedicated student portal with personal enrolled courses, resume lesson video player, quiz taking, assignment submissions, achievements, and study notes.
- **Instant Role Switcher**:
  - Toggle between Admin UI and Student UI directly from the Topbar pill or Sidebar switcher.
  - 1-click launch buttons on the Login page.
- **Course & Content Management**:
  - Course curriculum management, lesson progression tracking, and video player.
  - Rich interactive dashboards with KPI metrics, charts, and activity streams.

## Tech Stack
- **Framework**: React 18
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Charts**: Recharts
- **Bundler**: Vite

## Getting Started

### Installation

